## 1. Концепция и позиционирование

**Призма** — приложение для планирования, анализа и контроля команд.

### Главная метафора

Восьмилучевая звезда — отсылка к Полярной звезде. Команды теряются в задачах, дедлайнах, статусах. Призма — *компас*. Один взгляд на дашборд — и видно, куда движется команда.

### Позиционирование

В категории productivity-инструментов (Linear, Notion, Asana, ClickUp, Monday) все говорят одно и то же: «помогаем команде эффективно работать». Призма занимает свободную нишу — **«помогаем команде удерживать курс»**.

Это не таск-трекер, не PM-инструмент, не календарь. Это **компас**.

### Ключевые слова

- курс, траектория, ориентир, дрейф
- сверить курс, скорректировать траекторию
- придерживаться направления

## 2. Anatomy

Знак — восьмилучевая звезда с фиксированной геометрией.

### Конструкция

- **Главные лучи** (верх, низ): длина 12.5× от радиуса ядра, opacity 1.0
- **Боковые лучи** (слева, справа): длина 12.5× от радиуса ядра, opacity 0.7
- **Диагональные лучи** (4 шт.): длина 8× от радиуса ядра, opacity 0.45
- **Ядро**: круг с радиусом 4-5px (зависит от размера знака)

### Safe area

Минимум `x = 1/8 высоты знака` до любого другого элемента (текст, край контейнера, другая иконка).

### Минимальный размер

- **Цифровой носитель**: 12×12 px. Меньше — теряются диагональные лучи, нужна favicon-версия.
- **Печать**: 8 мм по диагонали.

### Ориентация

Только осями вверх-вниз-влево-вправо. Поворот на 22.5° или 45° — другая визуальная грамматика, не Призма.

### Файлы

- `assets/svg/logo/star.svg` — основной знак, 120×120 viewBox
- `assets/svg/logo/star-wordmark.svg` — звезда + кириллический wordmark «Призма»
- `assets/svg/logo/favicon-16.svg` — упрощённая версия для маленьких размеров
- `assets/svg/logo/app-icon-ios.svg` — мастер для iOS App Icon

## 3. Палитра

Полная палитра в JSON: `tokens/colors.json`. CSS-переменные: `tokens/theme.css`.

### Тёмная тема — Core

| Имя | HEX | Роль |
|---|---|---|
| Night | `#0A0A0F` | Главный фон. 60% поверхностей. |
| Twilight | `#1A1A22` | Карты, второй слой. |
| Star | `#FFFFFF` | Сам знак. Текст на тёмном. |
| Mist | `#5A5A64` | Подписи, второстепенный текст. |

### Светлая тема — Core

| Имя | HEX | Роль |
|---|---|---|
| Paper | `#FAFAF8` | Главный фон. Тёплый off-white. |
| Snow | `#FFFFFF` | Карты на Paper. |
| Linen | `#F0EDE5` | Третий слой, тонкие разделители. |
| Ink | `#1A1A22` | Знак, заголовки. Мягче чем `#000`. |
| Stone | `#7A7A82` | Подписи. |

### Signal — семантические цвета

Используются **только для статуса курса**, никогда как декорация.

| Значение | Тёмная | Светлая |
|---|---|---|
| На курсе | `#7FE8B5` | `#0F8A5F` |
| Дрейф | `#FFB347` | `#B5670A` |
| Сбился с курса | `#FF6B6B` | `#C13838` |
| Информация | `#6EC1E4` | `#1F6B96` |
| Инсайт | `#B084CC` | `#6B4488` |

### Принцип перевода тёмная → светлая

Не инверсия. Каждый цвет переходит на ту же hue-ось, меняется только светлота. Светло-зелёный «На курсе» (`#7FE8B5`) на светлой теме становится глубоким тёмно-зелёным (`#0F8A5F`) — глаз воспринимает их как «один и тот же зелёный».

### Пропорции в интерфейсе

- 60% — фон (Night/Paper)
- 20% — карты (Twilight/Snow)
- 15% — текст (Star+Mist / Ink+Stone)
- 5% — Signal-цвета (только статусы)

## 5. Иконки модулей

5 модулей продукта, каждый — вариация звезды. Это семья, не отдельные иконки.

### Файлы

- `assets/svg/modules/kurs.svg` — **Курс** — главный дашборд, полная звезда
- `assets/svg/modules/sled-puti.svg` — **След пути** — звезда с затухающими точками
- `assets/svg/modules/komanda.svg` — **Команда** — звезда + 3 спутника
- `assets/svg/modules/tseli.svg` — **Цели** — звезда внутри концентрических кругов
- `assets/svg/modules/ritualy.svg` — **Ритуалы** — две звезды в диалоге

### Принцип семейства

Звезда остаётся главной формой во всех 5 случаях. Каждый раздел продукта чувствуется как продолжение знака, а не как отдельный элемент.

## 6. Размеры

### Favicon

- 12×12 — упрощённая версия (только главные + боковые лучи)
- 16×16 — упрощённая версия
- 24×24, 32×32, 48×48, 64×64 — полная звезда

### App icons

- **iOS**: 1024×1024, padding 0, Apple применяет squircle-маску (radius 22.37%)
- **Android**: 512×512, circle mask
- **macOS**: 1024×1024, padding 12.5%
- **Windows**: 512×512, square corners

### Печать

Минимум 8 мм по диагонали. Для вышивки — одна нить (Star на тёмной ткани, Ink на светлой), без полутонов.

## 7. Tone of voice

### Четыре вектора голоса

| Хорошо | Плохо |
|---|---|
| Спокойный | Тревожный |
| Уверенный | Хвастливый |
| Точный | Многословный |
| Тёплый | Безразличный |

### Отношение к пользователю

| Хорошо | Плохо |
|---|---|
| Партнёр | Учитель |
| Информирует | Уговаривает |
| Уважает время | Требует внимания |
| На «вы» | На «ты», fam |

### Словарь Призмы

**Цели и направления**: курс, траектория, ориентир, точка отсчёта, азимут команды, направление.

**Состояния**: на курсе, в траектории, дрейф, отклонение, сбился с курса, держать ритм.

**Действия**: сверить курс, уточнить ориентир, увидеть путь, выбрать направление, скорректировать траекторию, следить за дрейфом.

### Примеры

| Хорошо | Плохо |
|---|---|
| «Команда сверяет курс на пятницу» | «Кто-нибудь, проведите ретро в пятницу плиз» |
| «Замечен дрейф в проекте Atlas» | «ВНИМАНИЕ! 3 задачи просрочены, срочно действуйте!» |
| «Призма видит, куда движется команда» | «Лучшая в мире платформа для команд 🚀» |
| «14 дней до цели. Курс выдерживается» | «Осталось 14 дней!! Не подведите команду!» |

### Главный слоган

**«Северная звезда для вашей команды.»**

Альтернатива для лендинга: «Команды теряются в задачах. Призма даёт ориентир.»

## 8. Темы

### Контекст применения

| Контекст | Default | Почему |
|---|---|---|
| Web app | auto/dark | Команды работают по 8 часов. Тёмная щадит глаза. |
| Mobile app | auto | Следуем за системой iOS/Android. |
| Лендинг | dark | Премиум, ясность, ассоциация с ночным небом. |
| Документация и блог | light | Долгое чтение, скриншоты. |
| Email-шаблоны | light | Большинство клиентов плохо рендерят dark. |
| Презентации, PDF | light | Печать и проекторы убивают тёмные темы. |
| Twitter/X | dark | 80% аудитории Twitter — dark mode. |
| Instagram, LinkedIn | mix | Чередовать. Создаёт ритм в ленте. |
| Принт, мерч | dark | Дешевле печатать одной нитью. Премиальнее. |

### Переключатель в интерфейсе

Три положения: **auto / dark / light**. По умолчанию `auto` — уважение к настройкам системы.

### Технический принцип

Один SVG, одна CSS-переменная для fill. Знак меняет цвет с `#FFFFFF` на `#1A1A22` через тот же transition, что и остальной интерфейс — 240ms ease-out, без crossfade.

## 9. Motion

Полная спецификация: `tokens/motion.json`. Готовые keyframes: `tokens/theme.css`.

### Четыре базовых жеста

#### 1. Emerge — сборка из ядра

- **Когда**: первое появление знака. Splash, page load, intro в onboarding.
- **Длительность**: 1100ms, easing `cubic-bezier(0.16, 1, 0.3, 1)`.
- **Последовательность**: ядро (0-400ms) → главные лучи (300-1000ms) → боковые → диагональные. Stagger 50ms между лучами одного типа.

#### 2. Breathe — дыхание в покое

- **Когда**: idle всегда. Hero, трей, фон. Знак никогда не статичен.
- **Длительность**: 4000ms, loop, easing `ease-in-out`.
- **Параметры**: `scale: 1.0 ↔ 1.04`, `opacity: 0.85 ↔ 1.0`.

#### 3. Pulse — сигнал внимания

- **Когда**: пришла нотификация, обнаружен дрейф.
- **Длительность**: 1600ms, loop, easing `ease-out`.
- **Параметры**: кольцо вокруг звезды, `scale: 0.4 → 1.6`, `opacity: 0.8 → 0`.

#### 4. Align — настройка курса

- **Когда**: смена контекста (модуль, команда, проект).
- **Длительность**: 1600ms, easing `cubic-bezier(0.34, 1.56, 0.64, 1)` (spring).
- **Параметры**: `rotation: -12° → 2° → 0°`.

### Принципы

1. **Спокойствие важнее эффектов.** Никаких bounce, jump (кроме align с лёгким spring).
2. **Уважать prefers-reduced-motion.** Breathe и pulse останавливаются.
3. **Одна анимация за раз.** Emerge → Breathe (default) → Pulse при сигнале → Align при смене контекста.
4. **Breathe всегда включён.** Это default idle-состояние. Другие жесты проигрываются поверх breathe и возвращают в него.

## 10. Splash screen

### Длительность

2400ms. Проигрывается полностью, даже если приложение готово раньше — это часть бренда.

### Три фазы

| Фаза | Время | Действие |
|---|---|---|
| EMERGE | 0-1000ms | Звезда собирается через жест emerge |
| SETTLE | 1200-2000ms | «ПРИЗМА» появляется с letter-spacing 14px → 8px, тaглайн через 400ms после |
| EXIT | 2000-2400ms | Одно полное дыхание, затем плавный выход в приложение |

### Контент

- **Знак**: звезда 96×96px по центру
- **Wordmark**: «ПРИЗМА», SF Pro Display 32px weight 200
- **Tagline**: «СЕВЕРНАЯ ЗВЕЗДА ДЛЯ ВАШЕЙ КОМАНДЫ» (Caption-стиль, letter-spacing 3px)

После завершения splash знак передаётся в idle — продолжает breathe в углу приложения, без перерыва.

## 11. Loaders

Три уровня в зависимости от ожидаемого времени.

### Иерархия

| Время | Что делать | Уровень |
|---|---|---|
| < 300ms | Не показывать ничего | NONE |
| 300ms - 2s | Inline pulse рядом с триггером | L1 |
| 2s - 6s | Page loader: знак + breathe + ring + caption | L2 |
| > 6s | Skeleton с shimmer + маркер-звезда | L3 |

### L1 — Inline pulse

- Размер: 16-24px
- Длительность: 1400ms loop
- Анимация: `scale 0.85 ↔ 1.0`, `opacity 0.5 ↔ 1.0`
- Контекст: «Сверяем курс…», «Сохраняем…», «Ищем…»

### L2 — Page loader

- Размер звезды: 48-64px по центру
- Анимация звезды: breathe 3000ms loop
- Анимация кольца: 2400ms loop, ease-out, `r: 4 → 30`, `opacity: 0.6 → 0`
- Caption под знаком: «УСТАНАВЛИВАЕМ КУРС»

### L3 — Skeleton

- Shimmer: 1600ms linear loop
- Gradient: `linear-gradient(90deg, #1A1A22 0%, #2A2A30 50%, #1A1A22 100%)`
- Background-size: 200% 100%, движется с 200% 0 → -200% 0
- Радиус строк: 4px
- Маленькая звезда в углу как маркер бренда

**Никогда не круговой спиннер.** Это не наш язык.

## 12. Illegal usage

Шесть запретов, защищающих знак.

1. **Не поворачивать.** Звезда всегда вертикально. Поворот — другая визуальная грамматика.
2. **Не раскрашивать.** Только Star (`#FFFFFF`) на тёмном или Ink (`#1A1A22`) на светлом. Никогда не цветные лучи.
3. **Не растягивать.** Только пропорциональное масштабирование. Никаких scale-x.
4. **Не менять пропорции лучей.** Главный 12.5×, боковой 12.5×, диагональный 8×, ядро 1×. Меняешь одно — ломаешь всё.
5. **Без свечения и теней.** Знак — плоская графика. Никаких glow, drop-shadow, neon.
6. **Не вкладывать в формы.** Звезда не помещается в треугольник, круг, щит. Она самодостаточна.
