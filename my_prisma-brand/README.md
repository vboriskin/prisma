# Призма — Brand Book

> Северная звезда для вашей команды.

Этот пакет содержит полный бренд-гайд для приложения **Призма** (планирование, анализ и контроль команд). Документ предназначен для передачи в Claude Code или любой другой AI-инструмент разработки, чтобы воссоздать визуальную систему один-в-один.

## Концепция

Призма — это **компас команды**. В категории productivity-инструментов все позиционируются одинаково: «помогаем команде работать». Призма занимает свободную нишу: «помогаем команде *удерживать курс*».

Знак — восьмилучевая звезда, ассоциирующаяся с Полярной звездой. Минималистичная, монохромная, читается с любого размера.

## Quick start для Claude Code

Если ты Claude Code и тебе нужно:

- **Сделать React-компонент логотипа** → `assets/svg/logo/star.svg` + `tokens/theme.css` для цвета через CSS-переменные
- **Настроить темизацию** → `tokens/colors.json` + `tokens/theme.css`. Светлая тема НЕ инверсия тёмной — каждый цвет имеет своего парного двойника
- **Реализовать анимации знака** → `tokens/motion.json` + `docs/08-motion.md`. Четыре жеста: emerge, breathe, pulse, align
- **Сделать splash screen** → `docs/09-splash.md` + используй emerge-анимацию из `motion.json`
- **Реализовать лоадеры** → `docs/10-loaders.md` + готовые SVG в `assets/svg/loaders/`
- **Иконки модулей** → `assets/svg/modules/` (5 штук) + `docs/04-modules.md`

## Принципы, которые нельзя нарушать

1. **Только вертикальная ориентация знака.** Никаких поворотов на 22.5°/45°.
2. **Только цвета `Star` (#FFFFFF на тёмном) или `Ink` (#1A1A22 на светлом).** Никакого окрашивания лучей.
3. **Никаких теней, glow, neon-эффектов.** Знак — плоская графика.
4. **Знак никогда не вкладывается в другие формы** (треугольники, круги, щиты).
5. **Соотношения лучей фиксированные:** главный 12.5×, боковой 8×, диагональный 5.5× от ядра.
6. **Default-состояние знака — `breathe` (дыхание).** Знак никогда не статичен в продукте.
7. **`prefers-reduced-motion` уважается.** Breathe и pulse останавливаются.
8. **Название только «Призма».** Никакого «Prisma» в текстах, заголовках, лендингах, документации, мерче.
