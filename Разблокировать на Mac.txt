  РАЗБЛОКИРОВКА НА Mac (если выскакивает «не удалось подтвердить»)
═══════════════════════════════════════════════════════════════════

Apple помечает скачанные из интернета файлы как «небезопасные» (атрибут
quarantine). Это нужно один раз снять. Делаете один из вариантов ниже.

───────────────────────────────────────────────────────────────────
  ВАРИАНТ 1 — Через настройки системы (без терминала, проще всего)
───────────────────────────────────────────────────────────────────

  1. Двойной клик по «Запустить (Mac).command» — выскочит ошибка.
  2. Откройте  →  Системные настройки  →  Конфиденциальность и
     безопасность.
  3. Прокрутите вниз. Увидите строку «Программа Запустить (Mac).command
     заблокирована».
  4. Нажмите «Открыть всё равно» / «Open Anyway».
  5. Введите пароль учётной записи Mac.
  6. Снова двойной клик по «Запустить (Mac).command» — теперь сработает.
  7. После этого работает обычным двойным кликом всегда.

───────────────────────────────────────────────────────────────────
  ВАРИАНТ 2 — Одна команда в терминале (быстрее, но нужен Терминал)
───────────────────────────────────────────────────────────────────

  1. Откройте программу «Терминал» (через Spotlight: Cmd+Пробел → ввести
     «Терминал»).
  2. Скопируйте СТРОКУ ниже и вставьте в Терминал, нажмите Enter:

       xattr -dr com.apple.quarantine ~/Downloads/v11_0

     ⚠️ Замените «~/Downloads/v11_0» на путь к папке, куда вы распаковали
     приложение (можно перетащить папку из Finder в Терминал — путь
     подставится сам).

  3. Закройте Терминал.
  4. Двойной клик по «Запустить (Mac).command» — теперь сработает без
     предупреждений.

───────────────────────────────────────────────────────────────────
  ВАРИАНТ 3 — Получить папку без quarantine изначально (для IT)
───────────────────────────────────────────────────────────────────

Если вы IT и раздаёте приложение коллегам — раздавайте через:

  · git clone <url>     ← НЕ помечается quarantine
  · Внутренний SMB / NFS общий диск   ← НЕ помечается
  · USB-флешка, принесённая с другого Mac, где quarantine уже снят

  Через Safari / Telegram / почту / Slack — ВСЕГДА получает quarantine
  и требует разблокировки одним из вариантов выше.

───────────────────────────────────────────────────────────────────
  ПОЧЕМУ НЕЛЬЗЯ СДЕЛАТЬ «БЕЗ РАЗБЛОКИРОВКИ»

  Чтобы скачанный файл запускался сразу — он должен быть «подписан
  Apple Developer ID» и проходить notarization. Это требует платной
  подписки разработчика Apple ($99/год) и процедуры подписания каждого
  обновления. Для внутреннего корпоративного инструмента это избыточно
  — поэтому используем один из вариантов выше.
