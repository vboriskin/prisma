## 2. Реконструкция Tone of Voice

> Документа нет — выводы из паттернов, которые повторяются в десятках файлов.

### Что просвечивает (явные принципы)

1. **Метафора «навигация / курс / компас / Северная звезда / ориентир»**
   Брендовая ось проявляется в каждом втором тосте и заголовке:
   - `'Курс сверен'` / `'Курс не сверен'` / `'Курс скорректирован'` (15+ мест: `app.js:369/376`, `app/llmAssistant.js:666/775`, `dataStore.js:101/143/1274`, `chat/chatActions.js:272/304/414`, `app/appSettings.js:526`, `views/integrationsView.js:237/242/299/364/441` и далее)
   - Заголовки: `'Курс ещё не проложен'`, `'Курс ровный'`, `'Курс квартала'`, `'Призма ждёт первый ориентир'` (`integrations/teamScanner2Renderer.js:3503`), `'Найден сохранённый курс'`, `'Сверить курс'`, `'Сверяем курс по CEO-сводке…'`
   - Слоганы: `'КОМПАС ДЛЯ ВАШЕЙ КОМАНДЫ'` (splash), `'Компас для вашей команды'` (welcome).
   - KPI: `'БЕЗ КУРСА'`, `'ДРЕЙФ'` (вместо «Drift / risky»).

2. **Без эмодзи в production UI** (декларация)
   В коде многократные комментарии-маркеры: `// V17.2 — emoji 🚧 / 📭 / ⚠️ убраны (Spine no-emoji rule)` (`onboarding/onboardingUI.js:296`); `'V17 P10 (art-director §3 + designer §3) — emoji 🎬/📂 → SVG glyphs'` (`index.html:669`). Принцип задекларирован, **но не выдержан** — см. находки C1 / C7 / C9.

3. **Обращение «вы» в UI, «ты» в чате**
   - UI / index.html / onboarding: всегда «вы»: `'Загрузите свой план'`, `'Нажмите кнопку «Фильтры»'`, `'выберите ориентир'`, `'Подтвердите'`.
   - Чат/LLM-fallback: «ты»: `'Уточни запрос'`, `'Нажми «Применить» или напиши «да»'` (`chat/chatActions.js:91/132`), `'Уточни фильтр'` — **внутреннее противоречие**.

4. **Запрет канцелярита в LLM-промптах** — частый явный запрет в system-prompt: `'Тон: профессиональный, без воды, без эмоций'` (`chat/chatPrompts.js:256`); **в собственных UI-текстах канцелярит присутствует** (см. находки H1/H4).

5. **Заголовки «эyebrow» — CAPS на 9–10 px** (BRAND_BOOK §spine-pill): `'ЧТО ТРЕБУЕТ КУРСА СЕГОДНЯ'`, `'КУРС КВАРТАЛА'`, `'ПРИЗМА'`, `'СЛЕД ПУТИ'`, `'РИТУАЛЫ'`, `'ЦЕЛИ'` (sidebar модули). Стабильно.

6. **Числа без эмоциональной окраски** — declared в activity-prompt: `'Не «Иван активнее Анны», а «Иван: 12 коммитов, 4 PR; Анна: 5 коммитов, 1 PR»'` (`chatActivityPrompts.js:58`). В ToV-плане — выдерживается.

7. **Антропоморфизация интеграций** — отдельный приём для error-маппинга (`views/integrationsView.js:_humanHttp`): «Jira не пускает», «Jira закрыла доступ», «Jira просит притормозить», «Jira не отвечает». Дружелюбно, но **только для Jira** — Bitbucket / Confluence / Sigma такой обработки не имеют → Курс сверен · Sigma: HTTP 503. Несимметрично.
