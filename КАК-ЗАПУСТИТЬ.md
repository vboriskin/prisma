# Как запустить СБОФ Планирование

## Один раз — установить Node.js

Это бесплатная программа, которая нужна для работы локального сервера (всё крутится у вас на компьютере, никуда не уходит).

- **Mac**: скачайте «LTS» версию с [nodejs.org](https://nodejs.org) и установите как обычно (двойной клик → «Далее»). Или, если стоит Homebrew: в терминале `brew install node`.
- **Windows**: скачайте «LTS» с [nodejs.org](https://nodejs.org), запустите установщик, нажимайте «Далее».

---

## Запуск приложения

### 🪟 Windows
1. Двойной клик по файлу **`Запустить (Windows).bat`** в папке.
2. Если SmartScreen ругается «Защитник Windows предотвратил запуск» — нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Один раз — потом не спросит.

### 🍎 Mac

> ⚠️ **macOS блокирует все скачанные из интернета скрипты.** Эта блокировка одноразовая — её надо снять один раз, потом всё работает двойным кликом.

**Если папку получили через `git clone` или сетевой диск (`smb://`):**
- Двойной клик по **`Запустить (Mac).command`** → работает сразу.

**Если скачали как ZIP с почты / Safari / Telegram (получите ошибку «Apple не удалось подтвердить»):**
- См. **`Разблокировать на Mac.txt`** в этой же папке — там три варианта разблокировки. Самый простой:
  1. Двойной клик → ошибка → закрыть.
  2. **Системные настройки → Конфиденциальность и безопасность** → внизу будет «Программа Запустить (Mac).command заблокирована» → **«Открыть всё равно»**.
  3. Снова двойной клик. Теперь работает всегда.

---

## Что произойдёт при запуске

1. Откроется чёрное окно с логом — это сервер. **Не закрывайте его пока пользуетесь приложением.**
2. Через 1–2 секунды автоматически откроется браузер.
3. Если браузер не открылся — откройте сами: [http://localhost:8080](http://localhost:8080).

---

## Как остановить

Просто закройте чёрное окно с логом. Данные сохранятся в браузере.

---

## Что-то пошло не так?

| Проблема | Решение |
|---|---|
| **Mac**: «Apple не удалось подтвердить файл» | См. `Разблокировать на Mac.txt` |
| **Windows**: «SmartScreen предотвратил» | «Подробнее» → «Выполнить в любом случае» |
| «Не найден Node.js» | Установите Node.js с [nodejs.org](https://nodejs.org) |
| «Все порты 8080–8089 заняты» | Закройте старые окна с логами |
| Открывается белая страница | Подождите 5 сек, F5 |
| Браузер не открылся | Откройте `http://localhost:8080` вручную |

## Для IT — как раздавать без проблем

Чтобы коллеги НЕ видели предупреждение Gatekeeper на Mac, раздавайте папку через:

- **`git clone`** во внутренний репозиторий
- **Сетевой диск** (SMB/NFS)
- **USB-флешка**

Эти каналы не помечают файлы как «скачанные из интернета» — приложение запускается сразу.

Файлы из Safari / Telegram / Slack / почты получают атрибут `com.apple.quarantine`, и macOS требует ручной разблокировки.

## Для тех, кто разбирается в командной строке

```bash
node launch.js              # авто-выбор порта + открытие браузера
node server.js              # сервер на 8080 без браузера
npm start                   # = node launch.js
npm run server              # = node server.js
```

См. `ARCHITECTURE.md` для технической информации.
