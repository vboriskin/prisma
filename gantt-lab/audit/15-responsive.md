# Адаптивность / responsive — экспертный аудит Ганта 3.0

> Эксперт: инженер адаптивных интерфейсов.
> Дата: 2026-05-24. Что покрыто: инъектированный CSS всех режимов, фикс-ширины, медиа-запросы, горизонтальный скролл, тач-таргеты. Метод: grep ширин/медиа + чтение CSS.

## Резюме

- **Адаптивности практически нет.** Во ВСЁМ инъектированном CSS (~850 строк) ровно **ОДИН** `@media` (gantt3.js:865, `.dc-grid` 2-кол→1-кол). Все остальные 19 режимов рассчитаны на широкий десктоп.
- **Десятки фикс-ширин**: сайдбар фокуса 250px, мастер-список сплита 300px, лейбл-колонки 196/210px, `min-width: 640/680/720px` (scrubber/anatomy/sc-gantt) → на ноуте 1280 и уже горизонтальный скролл, на планшете — каша.
- **`grid-template-columns: 210px repeat(var(--n),1fr)`** с 5–6 окнами: на узком экране окна-колонки сжимаются до <60px, пилюли вылезают.
- Это внутренний десктоп-инструмент, поэтому severity занижена, но при работе на 13″ MacBook (1280–1440 эффективных) проблемы уже реальны.

## Что сделано хорошо

- `.dc-grid` (split/zen деталь) корректно сворачивается 2→1 колонку на ≤720px — единственный, но правильный пример.
- Оверлеи занимают весь экран (`position:fixed; inset:0`) — базовая полноэкранность есть.
- Таблицы/сетки используют `1fr`-распределение — тянутся по ширине (проблема только на сужении).
- Внутренний скролл (`overflow:auto`) у тел оверлеев — вертикально не ломается.

## Приоритетный план

1. **P1** — breakpoint-система (RSP-01) + гибкие ширины сайдбаров/лейблов/таблиц (RSP-02).
2. **P2** — сворачивание mission/дорожек на узком (RSP-03/04); clamp-паддинги (RSP-05).
3. **P3** — тач-таргеты, collision вех, коллапс сайдбара фокуса.

> Примечание: инструмент внутренний (десктоп). Если 13″ MacBook — целевое устройство, RSP-01/02 поднимаются до P0 фактически.
