# UX / продукт — экспертный аудит Ганта 3.0

> Эксперт: senior product-дизайнер (UX, информационная архитектура, продуктовая стратегия).
> Дата: 2026-05-24. Что покрыто: тулбар `#section-gantt3` (22 кнопки), меню «Виды▾» (9 режимов), все режимы как продуктовые поверхности, сравнение с лаб-замыслом. Метод: чтение `gantt3.js` + `index.html` + скетчей.

## Резюме

- **Главный риск — не баги, а перегрузка поверхности.** На одной вкладке ~**20 режимов/инструментов** (11 тулбар-тогглов + 9 «Видов») плюс undo/redo/навигация/релиз/заметки/вехи/полный экран. Это галерея возможностей, а не сфокусированный рабочий инструмент.
- **Деление «тулбар vs Виды▾» нелогично** для пользователя: почему «Фокус»/«Нарратив»/«Курс» — кнопки, а «Сплит»/«Дзен»/«Центр управления» — в дропдауне? Признак: «оверлей на гриде» vs «полный экран» — это деление по реализации, а не по задаче.
- **Сильное дублирование job-to-be-done**: `split`≈`zen` (общая деталь эпика), `report`≈`deck`≈`mission` (KPI+риски+вехи), `Граф зависимостей`≈`Линза`, `Нарратив`≈`Отчёт`. 4 группы, где 1–2 экрана делают работу 8.
- **Режимы-«превью» в рабочем тулбаре** (Слияние: «реальный план не меняется»; Анатомия: референс) путают — это демо/доки, не рабочие инструменты.

## Карта режимов: какой вопрос решает каждый

| Режим | Вопрос | Дубль с |
|-------|--------|---------|
| Сетка (грид) | «Где что стоит по релизам?» | — (дом) |
| Сплит / Дзен | «Всё про этот эпик?» | **друг с другом** |
| Таблица | «Отсортировать/сравнить эпики» | частично mission |
| Отчёт / Дек / Центр управления | «Статус квартала для стейкхолдера» | **друг с другом** |
| Граф / Линза | «Что от чего зависит?» | **друг с другом** |
| Нарратив | «Рассказать план словами» | Отчёт |
| Фокус | «Одна команда крупно» | — (уникален) |
| Курс | «Где мы на таймлайне?» | вехи |
| История | «Как план дрейфовал?» | Переносы |
| Переносы | «Что переехало?» | История |
| Чипы / Подсказки / Слой / Burndown / Marquee / Peek / Inline / Radial | вспомогательные | — |

→ **8 «аналитических» режимов схлопываются в 3–4.**

## Рекомендация по группировке тулбара

1. **Смотреть**: Сетка · Деталь(split+zen) · Фокус · Таймлайн(курс+вехи)
2. **Фильтр/поиск**: Чипы · ⌘K · Подсказки
3. **Анализ**: Зависимости(граф+линза) · История(scrubber+переносы) · Burndown
4. **Статус/экспорт**: Статус(report+deck+mission) · Печать
5. **Справка**: Как читать · Анатомия · Слияние(демо)

## Что сделано хорошо

- Каждый режим по отдельности — продуманный и доведённый (после правок этой сессии — насыщенный, не «пустышка»).
- Empty-states во многих режимах; «Как читать?» как онбординг — правильный инстинкт.
- Фокус-дорожка и Центр управления — реально уникальные, ценные виды.
- Единый Esc/«Закрыть» в большинстве оверлеев.

## Приоритетный план

1. **P1** — схлопнуть дубли: Деталь (UX-02), Статус (UX-03), Зависимости (UX-04). Минус ~6 пунктов меню.
