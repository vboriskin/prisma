Скетч 14 · Вес оценки

Объём работы — в форме, а не в числе

Ширина каждой пилюли пропорциональна оценке её дисциплины из epic.est (BE→be, FE→fe…). Большая работа — широкая пилюля; мелкий хотфикс — узкая. Нейтральная шапка каждого релиза показывает сумму человеко-дней в колонке. Переключите «вес = оценка / равные», чтобы увидеть разницу.

Полоса слева — тип работы (категориальный, единый приглушённый канал). Ширина — оценка в днях. Статус — заливка/зачёркивание.

Ширина = min-width, линейно отображённая из epic.est[discipline] в диапазон 34–150px (клиппинг). Сумма по колонке = Σ est всех пилюль в релизе. В реальном приложении источник оценок — поля Release 2.0 / Jira story points по дисциплинам.
