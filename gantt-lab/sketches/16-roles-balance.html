Скетч 16 · Баланс ролей

Где не хватает рук по ролям

По каждой команде — горизонтальный стек спроса по ролям (BE / FE / QA / AN / …) против синтетической ёмкости роли. Где спрос превышает ёмкость, сегмент обведён красным off-course. Пунктир — суммарная ёмкость команды на оси спроса. Числа — спрос N / ёмкость M.

Спрос измеряется в

Спрос = сумма est (или число пилюль) по дисциплине во всех эпиках команды. Ёмкость роли — синтетическая константа CAPACITY в этом файле. В реальном приложении источник — state.employees[].roles, агрегированные по команде на окно планирования.
